## Как проводился аудит

- Workflow `wf_666a0ad8-14a` из 51 агента, только чтение:
  - 12 аудиторов, по одному на группу стадий, со сравнением с литературой через веб;
  - на каждую группу — скептик, который перепроверяет каждую находку по коду и пытается её
    опровергнуть, а также оценивает постановку каждого эксперимента;
  - для находок высокой и критичной серьёзности (ошибки, утечки, корректность, память, скорость) —
    независимое второе мнение;

    обучения;
  - критик полноты назвал шесть пропущенных вопросов, и каждый прошёл тот же цикл «аудит →
    проверка» (разделы «Добор» в `stages/13…18`).
- Числа по данным получены небольшими read-only пробами на `.venv/bin/python`: pyarrow по
  отдельным группам строк, несколько проб — модель на CPU с лучшим чекпойнтом. GPU, pytest,
  обучение и этапы конвейера не запускались.
- Сырые ответы всех агентов лежат в журнале workflow:
  `~/.claude/projects/-home-darkhan-projects-mini-pragma-v2/020f0bf3-d1c9-4373-b32e-17566c602bea/subagents/workflows/wf_666a0ad8-14a/journal.jsonl`.

  правки текста находок. Руками написаны только разделы 1–6 `REPORT.md`.

## Как читать карточку

- **Серьёзность**: оценка аудитора → оценка после проверки. «нет» — проверка сочла
  находку не дефектом.
- **Уверенность аудитора**: «точно» — проверено в коде или данных; «вероятно» — вывод из
  измерений без проверки на модели; «предположение» — гипотеза.
- **Проверка скептиком**: «подтверждено» или «подтверждено с поправками». Во втором случае текст
  проверки содержит исправленное утверждение, и **оно главнее текста аудитора**. Опровергнутых
  находок нет.
- **Второе мнение** — только у находок высокой серьёзности.
- **Цена исправления**: S / M / L.
