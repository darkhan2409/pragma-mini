# Признаки fraud_baseline

Строка — покупка клиента (reason=purchase) или transfer_out. Момент решения — время операции.
История — события того же клиента строго раньше операции; окно «за w» — t_i − w ≤ t < t_i.

| признак | тип | описание |
|---|---|---|
| `is_transfer` | числовой | исходящий перевод (иначе покупка) |
| `own_transfer` | числовой | перевод между своими счетами |
| `channel` | категориальный | канал операции (pos, ecom, qr, app) |
| `is_online` | числовой | онлайн-операция |
| `amount` | числовой | сумма операции, KZT |
| `log_amount` | числовой | log(1 + сумма) |
| `foreign_currency` | числовой | исходная валюта операции не тенге |
| `merchant_country` | категориальный | страна мерчанта |
| `is_foreign` | числовой | страна мерчанта не Казахстан |
| `mcc` | категориальный | MCC |
| `merchant_category` | категориальный | категория мерчанта |
| `merchant_name` | категориальный | название мерчанта |
| `hour` | числовой | час операции по местному времени |
| `weekday` | числовой | день недели (0 — понедельник) |
| `day_of_month` | числовой | число месяца |
| `txn_hours_since_prev` | числовой | часов с прошлой операции клиента |
| `txn_count_1h` | числовой | операций клиента за 1h до строки |
| `txn_count_1d` | числовой | операций клиента за 1d до строки |
| `txn_count_7d` | числовой | операций клиента за 7d до строки |
| `txn_count_30d` | числовой | операций клиента за 30d до строки |
| `txn_count_90d` | числовой | операций клиента за 90d до строки |
| `txn_sum_1h` | числовой | сумма операций клиента за 1h до строки, KZT |
| `txn_sum_1d` | числовой | сумма операций клиента за 1d до строки, KZT |
| `txn_sum_7d` | числовой | сумма операций клиента за 7d до строки, KZT |
| `txn_sum_30d` | числовой | сумма операций клиента за 30d до строки, KZT |
| `txn_sum_90d` | числовой | сумма операций клиента за 90d до строки, KZT |
| `declined_count_1h` | числовой | отклонённых операций за 1h до строки |
| `declined_count_1d` | числовой | отклонённых операций за 1d до строки |
| `online_count_1d` | числовой | онлайн-операций за 1d до строки |
| `foreign_count_1d` | числовой | операций за рубежом за 1d до строки |
| `foreign_share_90d` | числовой | доля операций за рубежом за 90d |
| `amount_to_mean_90d` | числовой | сумма / средняя операция за 90d |
| `log_amount_z_90d` | числовой | z-оценка log-суммы среди операций за 90d |
| `amount_to_max_prev` | числовой | сумма / наибольшая прошлая операция |
| `mcc_hours_since_prev` | числовой | часов с прошлой операции клиента этим MCC; пусто — впервые |
| `mcc_is_new` | числовой | клиент впервые платит этим MCC |
| `merchant_hours_since_prev` | числовой | часов с прошлой операции клиента у этого мерчанта; пусто — впервые |
| `merchant_is_new` | числовой | клиент впервые платит у этого мерчанта |
| `country_hours_since_prev` | числовой | часов с прошлой операции клиента в этой стране; пусто — впервые |
| `country_is_new` | числовой | клиент впервые платит в этой стране |
| `counterparty_hours_since_prev` | числовой | часов с прошлой операции клиента этому получателю; пусто — впервые |
| `counterparty_is_new` | числовой | клиент впервые платит этому получателю |
| `login_hours_since_prev` | числовой | часов с прошлого входа в приложение |
| `login_count_1h` | числовой | входов в приложение за 1h до строки |
| `login_failed_1h` | числовой | неудачных входов за 1h до строки |
| `new_device_login_1h` | числовой | входов с нового устройства за 1h до строки |
| `login_count_1d` | числовой | входов в приложение за 1d до строки |
| `login_failed_1d` | числовой | неудачных входов за 1d до строки |
| `new_device_login_1d` | числовой | входов с нового устройства за 1d до строки |
| `new_device_hours_since_prev` | числовой | часов с прошлого входа с нового устройства |
| `fraud_alert_1d` | числовой | антифрод-алертов банка за 1d до строки |
| `fraud_alert_30d` | числовой | антифрод-алертов банка за 30d до строки |
| `fraud_block_30d` | числовой | блокировок карты антифродом за 30d до строки |
| `income_sum_90d` | числовой | доходы (зарплата, пенсия, прочие) за 90d, KZT |
| `balance_before` | числовой | последний известный остаток повседневного счёта до строки |
| `amount_to_balance` | числовой | сумма / остаток до строки |
| `age` | числовой | полных лет на местную дату операции |
| `gender` | категориальный | пол |
| `region` | категориальный | регион на момент операции |
| `income_type` | категориальный | вид дохода на момент операции |
| `declared_income` | числовой | заявленный доход на момент операции |
| `merchant_city_other` | числовой | город мерчанта не совпадает с городом клиента |
| `days_since_bank_registered` | числовой | дней от вехи bank_registered до операции; пусто — вехи строго раньше ещё не было |
| `days_since_app_registered` | числовой | дней от вехи app_registered до операции; пусто — вехи строго раньше ещё не было |
